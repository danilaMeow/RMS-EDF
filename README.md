# Планирование периодических задач: RMS и EDF

Вариант: **медицинский монитор**.

Программа проверяет планируемость набора периодических задач τ = (C, T, D) двумя методами (Rate Monotonic и Earliest Deadline First), считает время отклика каждой задачи и строит временную диаграмму выполнения по RMS на интервале от 0 до гиперпериода.

## Модель

Каждая задача описывается тремя параметрами (время в миллисекундах):

| Параметр | Описание |
|---|---|
| `C` | время выполнения задачи |
| `T` | период |
| `D` | относительный дедлайн |

Приоритеты в RMS назначаются автоматически по периоду: меньший период означает более высокий приоритет.

Что считается:

- загрузка `U = Σ C/T`;
- тест Liu & Layland для RMS: набор планируем, если `U ≤ n·(2^(1/n) − 1)` (условие достаточное);
- условие EDF для неявных дедлайнов: набор планируем, если `U ≤ 1`;
- время отклика по рекуррентной формуле `R = C + Σ ceil(R / Tj) · Cj`, где сумма идёт по задачам с более высоким приоритетом. Итерация начинается с `R = C` и останавливается, когда `R` перестало меняться или превысило дедлайн;
- гиперпериод — наименьшее общее кратное периодов, до него строится диаграмма.

## Запуск

Нужен Python 3.10+, сторонние библиотеки не требуются. Запускать из корня проекта:

```
python src/main.py
```

По умолчанию данные берутся из `data/zadachi.json`. Другой файл (`.json` или `.csv`) можно передать первым аргументом:

```
python src/main.py data/zadachi.csv
```

## Формат входных данных

JSON:

```json
{"tasks": [{"name": "ЭКГ", "C": 1, "T": 4, "D": 4}]}
```

CSV: заголовок `name,C,T,D`, затем по строке на задачу. Все значения C, T, D целые.

|---|---|---|---|

## Результаты

| Задача | C | T | D | R | Уложилась |
|---|---|---|---|---|---|
| ЭКГ | 1 | 4 | 4 | 1 | Да |
| Пульсоксиметрия | 2 | 8 | 8 | 3 | Да |
| Тревожная сигнализация | 1 | 10 | 10 | 4 | Да |
| Отрисовка экрана | 2 | 20 | 20 | 7 | Да |

Итого по набору:

- загрузка U = 1/4 + 2/8 + 1/10 + 2/20 = 0,700;
- RMS: граница Liu & Layland для n = 4 равна 0,757, U = 0,700 ≤ 0,757, набор планируем;
- EDF: U = 0,700 ≤ 1, набор планируем;
- по времени отклика все задачи укладываются в дедлайны;
- гиперпериод равен 40 мс.

## Функции

- `Task` (`model.py`) хранит имя, C, T и D, проверяет корректность параметров.
- `load_json`, `load_csv`, `load_tasks` (`loader.py`) читают набор задач, формат выбирается по расширению файла.
- `utilization` считает загрузку U.
- `liu_layland_bound` считает границу n·(2^(1/n) − 1).
- `rms_schedulable` проверяет тест Liu & Layland.
- `edf_schedulable` проверяет условие U ≤ 1.
- `rms_priority_order` расставляет приоритеты по периоду.
- `response_time` считает время отклика одной задачи, `response_times` делает это для всего набора и проверяет дедлайны.
- `hyperperiod` находит гиперпериод.
- `simulate_rms` моделирует выполнение по RMS с вытеснением.
- `gantt` строит текстовую диаграмму.
- `main` выводит таблицу, итоги тестов и диаграмму.
